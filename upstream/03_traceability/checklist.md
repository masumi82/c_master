# トレーサビリティ表のレビュー観点

レビューする人（Claude を含む）はこの一覧を基準に見る。

- [ ] 要件定義書の要件 ID が、機能・非機能ともすべて表にあるか（1〜2章）
- [ ] 「基本設計の章・項目」列に空欄がないか。空欄は設計漏れなので、基本設計書に戻して埋めたか（1〜2章）
- [ ] 受入テストの観点が顧客の言葉で書かれ、結合テストの観点が開発側の言葉で書かれているか。同じ文を2列に書いていないか（1章）
- [ ] 逆引きに行があり、要件のない設計項目について「要件に追加」か「削る」の判断が書かれているか（3章）
- [ ] 表を作った結果として直した箇所が、要件定義書と基本設計書の変更履歴に残っているか
